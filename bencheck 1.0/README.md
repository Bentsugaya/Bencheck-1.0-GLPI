# BenCheck (GLPI 11)

Installation / mise à jour :
1. Copier le dossier `bencheck` dans `glpi/plugins/` (ou `glpi/marketplace/`).
2. Configuration > Plugins : Installer (ou Mettre à jour) puis Activer.
3. Configuration > Plugins > BenCheck : créer des checklists et leurs items (glisser-déposer pour réordonner).

Dans un ticket : section « Checklist » du panneau de droite (pas d'onglet) > choisir une checklist > Appliquer. Items cochables,
réorganisables par glisser-déposer, ajout d'items libres.
Option : application automatique d'une checklist aux tickets créés depuis un formulaire donné.

Testé sur GLPI 11.0.X
