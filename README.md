# BenCheck

BenCheck is a GLPI plugin that adds customizable checklists directly to tickets. It helps technicians follow standardized procedures, track completed tasks, and ensure that no critical step is missed during ticket processing.

## Features

- ✅ Add checklists to GLPI tickets
- ✅ Create fully customizable task lists
- ✅ Automatic checklist assignment based on ticket type or form
- ✅ Task validation with user and date tracking
- ✅ Improved process compliance and service quality
- ✅ Native integration with GLPI 11

## Installation

1. Download the latest release.
2. Extract the plugin into:

   ```
   glpi/plugins/bencheck
   ```

3. Navigate to:

   ```
   Administration → Plugins
   ```

4. Install and enable **BenCheck**.

## Requirements

- GLPI 11.x
- PHP version supported by your GLPI installation
